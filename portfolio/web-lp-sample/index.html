Implementation

依存ライブラリなしで、軽量・保守しやすい構成を意識しています。

01

Responsive

デスクトップからスマートフォンまで1つのHTMLで最適化。clamp()とGridを使い、過度なブレークポイント依存を避けています。

02

Accessible

適切な見出し構造、aria-label、ボタン要素、prefers-reduced-motionを採用し、基本的なアクセシビリティを考慮しています。

03

Maintainable

CSS変数と小さなコンポーネント単位で整理。外部フレームワークなしでも修正箇所を追いやすい設計です。
