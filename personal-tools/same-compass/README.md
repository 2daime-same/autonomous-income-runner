# SAME COMPASS

投資・大学・開発・収益化・生き物・生活など、種類の違う候補を一つの画面で整理するローカルファーストの意思決定ダッシュボードです。

「やりたいことが多すぎて、今やるべき一件がぼやける」「高リスク判断を勢いで進めたくない」「ChatGPTへ相談するたびに前提を説明し直す」という問題を、次の3つに分けて処理します。

1. **優先順位** — 効果、緊急度、根拠、複利性、興味、可逆性から価値を計算し、下振れ・時間・費用を差し引きます。
2. **判断ゲート** — 投資や大きな支出などは、採用理由、撤退条件、再評価日が欠けている限り「実行可」にしません。FOMOを申告すると24時間冷却します。
3. **相談用コンテキスト** — 上位候補、止まっている理由、撤退条件をMarkdownへまとめ、ChatGPTへそのまま貼れる形にします。

## 特徴

- 外部API、アカウント、課金、ビルド工程なし
- データはブラウザの `localStorage` のみに保存
- JSONバックアップと復元
- スマートフォン対応
- 投資判断、試験・提出、開発実験、収益案件、生き物予定の入力テンプレート
- PWA対応。配信後はホーム画面へ追加してオフライン利用可能
- 依存パッケージなし
- Node.js標準テストのみ

## 起動

ES ModulesとService Workerを使うため、ファイルを直接開くのではなくローカルHTTPサーバーから起動します。

```bash
cd personal-tools/same-compass
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## スコアの考え方

現在のモードごとに重みを変えます。

| モード | 重視するもの |
|---|---|
| 資産最大化（1〜2年） | 根拠、下振れ管理、複利性、可逆性 |
| 試験・提出集中 | 緊急度、失点回避、完了確率 |
| 開発スプリント | 技術資産、再利用性、興味、小さな検証 |
| 回復・整備 | 詰まりの解消、健康、次の集中を作ること |

概念上は次の計算です。

```text
優先度 = 重み付き価値 − 下振れペナルティ − 時間ペナルティ − 費用ペナルティ + 期限ボーナス
```

表示される点数は絶対的な価値ではなく、**現在登録されている候補を同じ基準で比較するための補助線**です。高リスク判断で必要情報が不足している場合は、点数が高くても49点以下に制限されます。

## プライバシー

このディレクトリには個人の保有銘柄、学校情報、予定、認証情報などを含めません。入力内容は外部へ送信されません。ただし、ブラウザデータの削除で消えるため、必要に応じて「整理・共有」画面からJSONを保存してください。

## 設計上の境界

- 売買や支払いを自動実行しません。
- スコアは市場予測や医療・法律判断を代替しません。
- GitHubへ個人データを同期しません。
- 高リスク判断は「速く決める」より「前提が崩れたときに止まれる」ことを優先します。
